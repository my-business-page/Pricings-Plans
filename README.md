## Maintenance

Routine care includes minor text and image changes, basic content updates, bug/error fixes, broken-link fixes, basic compatibility checks, small layout adjustments and functionality monitoring.

## Complimentary change requests

Each package includes 15 complimentary change requests. Eligible examples include new pages, design refreshes, feature additions, booking/shop updates and larger content updates. One eligible request uses one chance; confirm scope before work begins. Requests beyond the allowance and third-party costs may be quoted separately.

## Payment structure

50% advance to begin; remaining 50% after delivery and the customer's satisfaction with the completed website.
